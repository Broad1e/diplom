# План реализации

Изменения в проекте ведём в одном [репозитории на GitHub](https://github.com/Broad1e/diplom). Разработка агента начинается с Windows. Для демонстрации, проверки качества прогноза и испытаний под нагрузкой используем воспроизводимые синтетические ряды. Если консультант предоставит реальные данные, добавим проверку на полученной истории.

| Этап | Что делаем | Результат этапа |
| --- | --- | --- |
| 1. Контракты и каталог метрик | Уточняем семантику Windows-метрик, идентификаторы, единицы, поля запросов и правила подтверждения. Фиксируем примеры обычного измерения, повтора и некорректной точки. | Известно, какие данные проходят через каждый компонент и как их проверить. |
| 2. Сбор, запись и история | Реализуем Windows-агент, генератор, Go-сервер и запись в согласованную TSDB. Проверяем одиночный и пакетный режимы, повторную отправку и ограниченный буфер. | Агент и генератор отправляют измерения. API выдаёт историю, а сбои и повторы проверены на стенде. |
| 3. Прогноз и интерфейс | Реализуем фоновый расчёт на Python. Добавляем панель, вход администратора, прогнозы по всему набору метрик и слайдер для порогов. | Можно пройти сквозной сценарий на синтетических данных и показать влияние порога на предупреждения. |
| 4. Испытания | Измеряем пропускную способность и задержку записи, проверяем поведение при отказе и сравниваем варианты чтения истории. Для прогноза проводим сравнение на отложенных синтетических сценариях. | Сценарии можно повторить, а таблицы результатов объясняют выбор настроек записи и методов прогноза. |
| 5. Подготовка к защите | Готовим демонстрацию, описываем ограничения экспериментов и вносим согласованные изменения по ревью. При появлении реальных рядов проверяем, какие выводы на них сохраняются. | Платформу можно запустить и показать на Windows-стенде. Результаты испытаний готовы для записки и защиты. |

## Структура репозитория

Каталоги реализации добавляются по мере появления кода.

| Путь | Назначение |
| --- | --- |
| `agent/` | Агент мониторинга Windows на Go. |
| `backend/` | Приём измерений, хранение и программный интерфейс на Go. |
| `forecasting/` | Подготовка рядов и прогнозы на Python. |
| `frontend/` | Панель мониторинга и настройки на React. |
| `benchmarks/` | Генератор и воспроизводимые сценарии испытаний. |
| `docs/` | [Требования](REQUIREMENTS.md), [архитектура](ARCHITECTURE.md), [решения](DECISIONS.md) и этот план. |
| `AGENTS.md` | Правила работы в репозитории. |
